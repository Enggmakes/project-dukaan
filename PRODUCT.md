# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

- **Primary Audience**: Engineering and Computer Science students, capstone teams, self-taught developers, and researchers preparing academic submissions, portfolio projects, or hackathons.
- **Secondary Audience**: Makers and hobbyists building IoT, Robotics, or embedded hardware projects.
- **Admins & Engineers**: The internal ProjectDukaan engineering team managing project listings, custom build requests, order fulfillment, hardware tracking numbers, and customer inquiries.

## Product Purpose

ProjectDukaan is an engineering marketplace and custom project studio designed to eliminate friction in building and deploying complex technical projects. It provides:
1. **Production-Ready Projects**: Instant-access, fully documented, verified software repositories and datasets across AI/ML, Computer Vision, Robotics, IoT, Web, Mobile, Blockchain, and Cybersecurity.
2. **Hardware Delivery Kits**: Physical components, microcontrollers, and sensor kits pre-configured and shipped for hardware capstones.
3. **Custom Engineering Studio**: Direct request submission where students and teams can get custom engineering architectures, documentation, and source code built to their exact requirements.

## Positioning

Unlike generic boilerplate code repositories or low-quality academic report sellers, ProjectDukaan delivers **fully verified, production-grade engineering projects** complete with setup guides, architecture diagrams, datasets, video walkthroughs, instant payment via Cashfree, and hardware shipping support with a 7-day guarantee.

## Operating Context

- **Marketplace Browsing**: Categorized exploration by domain, price filters, difficulty levels (Beginner, Intermediate, Advanced), and searchable technology stacks.
- **Project Deep-Dive**: Media screenshots, YouTube video walkthrough embeds, tabbed architecture diagrams, "What's Included" breakdown with dynamic iconography, and verified customer reviews.
- **Checkout & Fulfillment**: Integrated Cashfree payment gateway supporting UPI, QR, Credit/Debit cards, and Netbanking, with instant digital asset downloads and order tracking.
- **Custom Project Pipeline**: Multi-step request intake allowing file/specification uploads, budget categorization, and status tracking (New, Reviewing, Contacted, Quoted, In Progress, Delivered).
- **Admin Control Center**: Real-time management of product inventory, customer inquiries, order dispatch/tracking IDs, and lead qualification.

## Capabilities and Constraints

- **Stack**: React 18, Vite, TypeScript, Tailwind CSS, Radix UI, Lucide Icons, React Router v6, React Helmet Async.
- **Backend & Storage**: Supabase (PostgreSQL database, Authentication, Row-Level Security, Storage buckets for custom request attachments and receipts).
- **Payments**: Cashfree JS SDK + Serverless API routes for order creation and verification.
- **Design System**: Apple Liquid Glass (WWDC 2025/2026 meta-material) featuring clear refractive lensing, specular rim lighting, and fluid spring physics.
- **Fulfillment Models**:
  - *Digital Delivery*: Instant source code (.zip), dataset, and PDF documentation access.
  - *Physical Delivery*: Pre-configured hardware kits dispatched with tracking numbers.
